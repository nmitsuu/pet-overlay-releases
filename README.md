# Pet Overlay

Downloads for Pet Overlay (Aion 2). The app checks this page by itself and installs updates on its own.

**First install:** download [PetOverlay.zip](https://github.com/nmitsuu/pet-overlay-releases/releases/latest/download/PetOverlay.zip),
right-click it and choose **Extract All** (for example into Documents), then open the **Pet Overlay** folder and
double-click **Pet Overlay.bat**. Click **Yes** when Windows asks to allow changes. If the PC doesn't have Npcap
yet, its official installer opens once: click Install.

Read-only: the app only watches the game's network traffic and the screen. It never changes the game.
